# Modelagem de Oferta

Skill para criar e avaliar ofertas low-ticket com base na metodologia e nas fontes de referência incluídas.

## Instalação no Codex

No Codex/ChatGPT, envie esta mensagem com o link abaixo:

```text
Instale esta skill:
https://github.com/Gabr1elcastro/modelagem-de-oferta/tree/main/.agents/skills/modelagem-de-oferta
```

Na próxima mensagem, ela estará disponível como:

```text
$modelagem-de-oferta
```

## Uso manual ou desenvolvimento

Após clonar este repositório, abra o Codex na raiz dele. A skill será descoberta em `.agents/skills/modelagem-de-oferta`.

Use explicitamente:

```text
$modelagem-de-oferta
```

Ou descreva um pedido compatível, por exemplo: “modele uma oferta low-ticket para [público/produto]”.

## Atualizar

Atualize os arquivos da skill, revise a mudança e faça commit. Quem clonou o repositório recebe a versão nova com `git pull`.

## Conteúdo de referência

As transcrições em `references/transcricoes/` são fontes primárias da metodologia. Distribua este repositório apenas a pessoas autorizadas a acessar esse material.
